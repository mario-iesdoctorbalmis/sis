Documentación técnica y Markdown

1. Documentación técnica

Section titled “1. Documentación técnica”

La documentación técnica es el conjunto de materiales escritos que describen cómo instalar, configurar, usar o mantener un sistema o aplicación. Es una competencia esencial para cualquier técnico de sistemas.

TipoPropósitoEjemplos
Manual de usuarioGuiar al usuario finalGuía de instalación, pasos de configuración
Manual de administraciónProcedimientos para el técnicoBackup, GPOs, scripting
Registro de incidenciasTrazabilidad de problemas y solucionesTicket de soporte, log de cambios
README / WikiIntroducción rápida de un proyectoGitHub README, Confluence

2. Markdown

Section titled “2. Markdown”

Markdown es un lenguaje de marcado ligero que se convierte en HTML. Es el formato estándar para documentación técnica en plataformas como GitHub, GitLab o Stack Overflow, y la base de herramientas como MkDocs.
