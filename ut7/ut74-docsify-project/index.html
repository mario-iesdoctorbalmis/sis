Proyecto: Portfolio técnico del curso

Conexión con el currículum

RA 7: Elabora documentación valorando y utilizando aplicaciones informáticas de propósito general.

  • c) Se han realizado tareas de documentación mediante el uso de herramientas ofimáticas.
  • f) Se han utilizado métodos de búsqueda de documentación técnica mediante el uso de servicios de Internet.

¿Qué es el portfolio?

Section titled “¿Qué es el portfolio?”

A lo largo del curso construirás un sitio de documentación técnica con Docsify que recoge el trabajo de cada unidad. No es un ejercicio puntual de UT7: es un repositorio real que irás ampliando unidad a unidad hasta el final del módulo.

El portfolio tiene dos objetivos:

  1. Técnico: aprender a documentar sistemas de forma profesional, con control de versiones.
  2. Académico: servir como evidencia de todo lo aprendido en el módulo — es la entrega de evaluación del RA7.

Documenta mientras practicas

Es mucho más fácil escribir los pasos justo cuando acabas de hacerlos. No lo dejes para el final.

Arranque en UT7

Section titled “Arranque en UT7”

En esta unidad creas la base del portfolio. Las secciones de cada UT se irán completando cuando trabajéis esos contenidos.

Requisitos del sitio al entregar UT7

Section titled “Requisitos del sitio al entregar UT7”
  • Proyecto Docsify creado con el nombre portfolio-si
  • index.html configurado: name con tu nombre, loadSidebar activo, _sidebar.md con la estructura completa del curso (ver abajo)
  • README.md con: quién eres, qué es el portfolio y una tabla de las unidades con su estado (✅ completado / 🔄 en progreso / ⏳ pendiente)
  • Al menos 2 páginas de contenido real (puedes usar lo trabajado en esta unidad UT7)
  • Cada página con al menos: una tabla, un bloque de código y una admonición
  • Repositorio público en GitHub con nombre portfolio-si y al menos 3 commits con mensajes descriptivos
  • Sitio publicado en GitHub Pages con URL funcional

¿Primera vez con Git y GitHub?

Si todavía no has creado un repositorio en GitHub ni sabes qué es un commit, sigue primero el manual Git y GitHub para principiantes antes de continuar con esta página.

Estructura de navegación del sitio

Section titled “Estructura de navegación del sitio”

Copia este bloque en tu _sidebar.md como punto de partida. Las páginas de las unidades que aún no hemos visto pueden estar vacías o con un simple # En construcción.

Cómo crece el portfolio a lo largo del curso

Section titled “Cómo crece el portfolio a lo largo del curso”
MomentoQué añades
UT7 (ahora)Estructura completa, README.md, contenido de la unidad actual
Cada UT posteriorCompletas las páginas de esa UT mientras la estás trabajando
Final de cursoPortfolio completo → entregable de evaluación del RA7

Cuando llegues a Entorno de Desarrollo aprenderás Git con profundidad. En ese momento ya tendrás un proyecto propio real con el que practicar: este repositorio.
