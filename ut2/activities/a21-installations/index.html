A21 — Instalación de sistemas operativos, controladores y software

👥 Modalidad

Actividad individual. Cada alumno entrega la documentación de las tareas realizadas con sus capturas de pantalla y explicaciones correspondientes.

⚠️ Precauciones

  • Trabaja siempre sobre las máquinas virtuales indicadas (T1Linux y T2Windows), nunca sobre el disco del equipo anfitrión.
  • Instalación desatendida:
    • GNU/Linux: no tiene en cuenta la instalación desatendida; aunque no se marque, pedirá datos durante el proceso.
    • Windows: depende de la ISO utilizada.

📎 Anexo de consulta: VirtualBox básico

Si es tu primera vez creando o configurando máquinas virtuales, consulta antes el Anexo A21 — Guía básica de Oracle VirtualBox.

Tarea 1. Instalar GNU/Linux y actualizar

Section titled “Tarea 1. Instalar GNU/Linux y actualizar”

1.1. Creación e instalación de T1Linux

Section titled “1.1. Creación e instalación de T1Linux”
  • Crea una máquina virtual llamada T1Linux con:
  • Disco duro dinámico: 45 GB
  • Memoria RAM: 2500 MB
  • Memoria de vídeo: 128 MB
  • Audio: deshabilitado (quitar audio)
  • Red: refrescar la dirección MAC de la máquina virtual
  • Descarga e instala Lubuntu desde el servidor FTP (carpeta SI):
  • Usuario: admin | Contraseña: admin
  • Tipo de instalación: mínima (el instalador de Lubuntu pregunta por mínima, normal o completa)
  • Actualizaciones: no actualizar mientras instala
  • Particionado: Borrar disco (dentro de la máquina virtual)

1.2. Actualización en Lubuntu

Section titled “1.2. Actualización en Lubuntu”
  • Actualiza primero todas las aplicaciones y después el sistema a su última versión (en modo texto o gráfico).
  • No esperes a que termine por completo: realiza una captura de pantalla del proceso y detén la actualización con Ctrl + C.

1.3. Caso práctico: EndeavourOS

Section titled “1.3. Caso práctico: EndeavourOS”
  • Imagina que tienes instalado EndeavourOS. Explica cómo actualizarías el sistema en modo texto indicando el comando o comandos completos.

Tarea 2. Instalar Windows

Section titled “Tarea 2. Instalar Windows”

2.1. Creación e instalación de T2Windows

Section titled “2.1. Creación e instalación de T2Windows”
  • Crea una máquina virtual llamada T2Windows con:
  • Sistema operativo: Windows 10 (Tiny10) / Windows 11 Pro
  • Disco duro dinámico: 75 GB
  • Memoria RAM: 2500 MB
  • Memoria de vídeo: 128 MB
  • Audio: deshabilitado (quitar audio)
  • Red: refrescar la dirección MAC de la máquina virtual
  • Usuario: admin | Contraseña: admin
  • Después de instalar el sistema operativo, comprueba que todo funciona correctamente.

2.2. Recurso de red (FTP del profesor)

Section titled “2.2. Recurso de red (FTP del profesor)”
  • Añade el recurso de red (FTP del profesor) en el ordenador anfitrión.
  • Comprueba y responde: ¿puedes añadirlo también desde dentro de la máquina virtual? Justifica tu respuesta.

Tarea 3. Controladores

Section titled “Tarea 3. Controladores”

Ayer estabas jugando al GTA VI y todo iba de maravilla, hasta que hoy, tras la última actualización automática de Windows, la conexión a Internet comienza a fallar: la señal va y viene, y eso está arruinando tus partidas… por ahora.

Tras pensarlo un momento, llegas a la conclusión de que la actualización de Windows ha podido afectar a los drivers de la tarjeta de red y te dispones a actualizarlos.

  • Identificación del hardware: ¿cómo has averiguado que tu placa base es MSI PRO B850-S EVO? Indica el software o utilidades usadas.
  • Desinstalación previa: explica y muestra cómo desinstalar previamente el controlador de red.
  • Actualización paso a paso: indica todos los pasos a seguir para realizar la actualización con capturas de pantalla.

Tarea 4. Línea de comandos GNU/Linux: instalación de apps en Lubuntu

Section titled “Tarea 4. Línea de comandos GNU/Linux: instalación de apps en Lubuntu”
  • Actualiza el sistema previamente.
  • Instala Weather Monitor y/o FileZilla desde la tienda de aplicaciones.
  • Si no aparece la tienda, busca cuál es la tienda de la distribución e instálala mediante comandos.
  • Usando apt, instala Kazam y/o Visual Studio Code.
  • Con Flatpak, instala OBS (navega a su web y descarga el fichero) y/o Spotify (flathub.org/apps/com.spotify.Client).
  • Si no puedes instalarlo con Flatpak, documéntalo y prueba con apt.

Tarea 5. Línea de comandos Windows: winget

Section titled “Tarea 5. Línea de comandos Windows: winget”

Nivel básico

Section titled “Nivel básico”
  1. Buscar aplicaciones:
    • Usa winget search <nombre> para localizar VLC, 7-Zip y Notepad++. Anota sus IDs.
  2. Instalar una aplicación:
    • Instala 7-Zip usando su ID: winget install <ID>
  3. Mostrar información:
    • Consulta datos del paquete VLC con: winget show <ID>

Nivel intermedio

Section titled “Nivel intermedio”
  1. Actualizar aplicaciones:
    • Lista actualizaciones disponibles: winget upgrade
    • Actualiza solo Notepad++: winget upgrade <ID>
  2. Desinstalar software:
    • Desinstala 7-Zip: winget uninstall <ID>
  3. Exportar programas:
    • Genera un JSON con los programas instalados: winget export -o apps.json
  4. Importar programas:
    • En otra máquina, importa la lista: winget import apps.json

Nivel avanzado

Section titled “Nivel avanzado”
  1. Instalar versiones concretas:
    • Comprueba versiones disponibles de Node.js y elige una: winget install <ID> --version <versión>
  2. Uso de parámetros avanzados:
    • Instala Google Chrome sin interacción:
  3. Gestión de orígenes:
    • Lista los orígenes configurados: winget source list
    • Deshabilita y vuelve a habilitar el origen msstore.
