Servidor de Impresión (Print Server)

Conexión con el currículum

RA 6: Opera sistemas en red gestionando sus recursos e identificando las restricciones de seguridad existentes.

  • c) Se han explotado servidores de ficheros, servidores de impresión y servidores de aplicaciones.

Servidor de Impresión

Section titled “Servidor de Impresión”

Un servidor de impresión centraliza la gestión de las impresoras de la red. Los usuarios envían sus trabajos al servidor, que los gestiona y los envía a la impresora física correspondiente.

Ventajas sobre la conexión directa

Section titled “Ventajas sobre la conexión directa”
Sin servidor de impresión Con servidor de impresión
Cada PC instala sus propios drivers Drivers centralizados en el servidor
Sin cola de impresión compartida Cola gestionada y auditable
Sin control de quién imprime Permisos por usuario o grupo
Impresora inutilizable si el PC que la comparte se apaga Disponible mientras el servidor esté activo
Actualización de drivers en cada equipo Actualización centralizada en el servidor

Instalación del rol Print Server

Section titled “Instalación del rol Print Server”
  1. En Server Manager → Manage → Add Roles and Features
  2. En Server Roles, marca Print and Document Services
  3. En Role Services, selecciona:
    • Print Server (obligatorio)
    • Internet Printing — opcional, permite imprimir vía HTTP
    • LPD Service — opcional, compatibilidad con sistemas Unix/Linux
  4. Finaliza la instalación

Añadir una impresora al servidor

Section titled “Añadir una impresora al servidor”

Desde el Panel de control

Section titled “Desde el Panel de control”
  1. Abre Dispositivos e impresoras (o Configuración → Bluetooth y dispositivos → Impresoras y escáneres)
  2. Haz clic en Agregar impresora
  3. Si la impresora aparece en la lista, selecciónala
  4. Si no aparece, elige La impresora que quiero no está en la lista y:
    • Selecciona Agregar una impresora local o de red con configuración manual
    • Elige Crear un nuevo puerto → Standard TCP/IP Port
    • Introduce la dirección IP de la impresora (p. ej. 192.168.1.50)
    • Instala el driver correspondiente al modelo

Desde Print Management (recomendado)

Section titled “Desde Print Management (recomendado)”

Print Management (printmanagement.msc) es la consola centralizada para gestionar todas las impresoras del servidor:

  1. Abre printmanagement.msc desde Server Manager → Tools
  2. Navega a Print Servers → [nombre del servidor] → Printers
  3. Clic derecho → Add Printer…
  4. Sigue el asistente: tipo de puerto, dirección IP y driver

Compartir una impresora

Section titled “Compartir una impresora”

Una vez instalada la impresora, hay que compartirla para que los clientes de la red puedan acceder a ella:

  1. Abre Dispositivos e impresoras
  2. Clic derecho en la impresora → Propiedades de impresora → pestaña Compartir
  3. Marca Compartir esta impresora
  4. Asigna un nombre de recurso compartido (p. ej. Ventas-HP)
  5. (Opcional) Marca Presentar trabajos de impresión en equipos cliente para mejorar la compatibilidad con clientes más antiguos

Permisos de impresión

Section titled “Permisos de impresión”

Los permisos se configuran en Propiedades de impresora → pestaña Seguridad:

Permiso Descripción
Imprimir Puede enviar trabajos de impresión propios
Administrar esta impresora Puede cambiar la configuración de la impresora
Administrar documentos Puede gestionar la cola: pausar y cancelar trabajos ajenos

Configuración típica de permisos

  • Todos (Everyone): solo permiso de Imprimir
  • Administradores: todos los permisos (Administrar esta impresora)
  • Grupos específicos (p. ej. GRP-Ventas): Imprimir + Administrar documentos si gestionan la cola

Gestión de la cola de impresión

Section titled “Gestión de la cola de impresión”

El servicio Print Spooler gestiona los trabajos de impresión pendientes.

Desde la interfaz gráfica

Section titled “Desde la interfaz gráfica”
  1. Doble clic en la impresora en Dispositivos e impresoras → se abre la cola
  2. Desde la cola puedes:
    • Pausar un trabajo individual o toda la impresora
    • Cancelar trabajos
    • Reanudar trabajos pausados

Desde PowerShell

Section titled “Desde PowerShell”

Cola bloqueada

Cuando una impresora queda “atascada” y no responde, lo más habitual es reiniciar el servicio Spooler y, si persiste, eliminar manualmente los archivos temporales en C:\Windows\System32\spool\PRINTERS.

Despliegue automático con GPO

Section titled “Despliegue automático con GPO”

En un dominio, las impresoras pueden desplegarse automáticamente a los usuarios mediante Group Policy:

  1. Abre gpmc.msc
  2. Edita una GPO aplicada a la OU correspondiente
  3. Ve a User Configuration → Windows Settings → Deployed Printers
  4. Clic derecho → Deploy Printer… e introduce la ruta UNC: \\WS-apellidoNombre\Ventas-HP
  5. La impresora se instalará automáticamente cuando los usuarios de esa OU inicien sesión

Ventaja en dominio

Con GPO, los usuarios no tienen que instalar manualmente las impresoras. Al iniciar sesión reciben automáticamente las impresoras asignadas a su OU o grupo.

Desde Windows 10/11

Section titled “Desde Windows 10/11”
  1. Abre el Explorador de archivos y navega a \\WS-apellidoNombre
  2. Doble clic en la impresora compartida → se instala automáticamente el driver desde el servidor
  3. O bien: Dispositivos e impresoras → Agregar impresora → escribir la ruta UNC
