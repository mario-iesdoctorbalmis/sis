Acceso Remoto

Section titled “Acceso Remoto”

Administrar un servidor sin estar físicamente delante de él es la norma en cualquier entorno profesional. Windows Server ofrece varias tecnologías de acceso remoto, cada una adaptada a distintos casos de uso.

Comparativa de tecnologías

Section titled “Comparativa de tecnologías”
Tecnología Puerto Protocolo Interfaz Uso típico
RDP 3389/TCP Propio (RDP) Escritorio gráfico completo Administración día a día

RDP — Escritorio Remoto

Section titled “RDP — Escritorio Remoto”

RDP (Remote Desktop Protocol) permite controlar el escritorio completo de un servidor Windows de forma remota, exactamente igual que si estuvieras sentado delante de él.

Activar el Escritorio Remoto en Windows Server

Section titled “Activar el Escritorio Remoto en Windows Server”

Desde Server Manager:

  1. En Server Manager → Local Server, haz clic en el enlace Remote Desktop: Disabled
  2. En la pestaña Remote, selecciona Allow remote connections to this computer
  3. (Recomendado) Deja marcada la opción Allow connections only from computers running Remote Desktop with Network Level Authentication (NLA)

Desde propiedades del sistema:

  1. Ejecuta sysdm.cpl
  2. Abre la pestaña Remote
  3. Selecciona la opción de permitir conexiones remotas

¿Quién puede conectarse por RDP?

Section titled “¿Quién puede conectarse por RDP?”

Por defecto, solo los administradores del sistema pueden conectarse por RDP.

Para permitir a otros usuarios conectarse:

  1. En Propiedades del sistema → Remote → Select Users…
  2. Haz clic en Add y añade los usuarios o grupos deseados (se añaden al grupo local Remote Desktop Users)

Sesiones simultáneas

Windows Server (sin licencias RDS) permite hasta 2 sesiones RDP simultáneas de administración. Para más sesiones concurrentes se necesita el rol Remote Desktop Services (RDS) con licencias de acceso cliente (CAL — Client Access License).

Conectarse desde el cliente

Section titled “Conectarse desde el cliente”

Desde Windows 10/11 con interfaz gráfica:

  1. Abre Conexión a Escritorio Remoto (busca mstsc en el Menú Inicio)
  2. En Equipo, introduce la IP o el nombre del servidor: 10.100.43.101 o WS-apellidoNombre
  3. (Opcional) En Opciones → General, introduce el nombre de usuario
  4. Haz clic en Conectar
  5. Acepta el aviso de certificado e introduce las credenciales

Seguridad del puerto RDP

El puerto 3389 es uno de los más atacados en Internet mediante fuerza bruta y exploits.

Medidas básicas de protección:

  • Activa siempre NLA (Network Level Authentication)
  • Limita las IPs que pueden conectarse con reglas de firewall
  • En servidores expuestos a Internet, usa VPN para acceder y mantén el 3389 cerrado externamente
  • Considera cambiar el puerto por defecto (aunque no es suficiente por sí solo)

PowerShell Remoting

Section titled “PowerShell Remoting”

PowerShell Remoting permite ejecutar comandos PowerShell directamente en un servidor remoto, sin interfaz gráfica. Es ideal para automatización, scripts y administración de múltiples servidores a la vez.

Usa el servicio WinRM (Windows Remote Management) para la comunicación.

Windows Admin Center

Section titled “Windows Admin Center”

Windows Admin Center es la herramienta de administración web moderna de Microsoft para Windows Server. Sustituye progresivamente a las MMC clásicas y a Server Manager.

Características principales

Section titled “Características principales”
  • Acceso desde cualquier navegador moderno (Chrome, Edge, Firefox)
  • Gestión de múltiples servidores desde un único panel
  • Módulos integrados: disco, red, eventos, tareas, usuarios y grupos, certificados, Hyper-V, etc.
  • No requiere instalar agentes adicionales en los servidores administrados

Instalación

Section titled “Instalación”
  1. Descarga el instalador desde aka.ms/windowsadmincenter
  2. Ejecuta el instalador en el servidor o en una estación de administración dedicada
  3. Accede desde el navegador: https://localhost:443

Alternativa moderna

Windows Admin Center es la evolución de Server Manager y las herramientas MMC clásicas. Microsoft lo recomienda para la administración del día a día en entornos modernos.

RSAT — Herramientas de Administración Remota

Section titled “RSAT — Herramientas de Administración Remota”

RSAT (Remote Server Administration Tools) permite administrar Windows Server desde una estación Windows 10/11, sin necesidad de abrir una sesión RDP.

Incluye herramientas como:

  • Active Directory Users and Computers (dsa.msc)
  • Group Policy Management Console (gpmc.msc)
  • DNS Manager (dnsmgmt.msc)
  • DHCP Manager
  • Print Management (printmanagement.msc)

Instalar RSAT en Windows 10/11

Section titled “Instalar RSAT en Windows 10/11”

Una vez instalado RSAT, las herramientas aparecen en Panel de control → Herramientas administrativas y se conectan automáticamente al servidor del dominio.
