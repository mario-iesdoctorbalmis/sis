Seguridad por capas (Defensa en profundidad)

Section titled “Seguridad por capas (Defensa en profundidad)”

La seguridad de un servidor no se limita a los permisos de archivos. Un enfoque profesional aplica múltiples capas de protección:

Si un atacante supera una capa, se encuentra con la siguiente. El objetivo es que comprometer el sistema requiera superar todas las capas.

Windows Defender Firewall

Section titled “Windows Defender Firewall”

El Firewall de Windows Defender filtra el tráfico de red entrante y saliente basándose en reglas. Es la primera barrera de protección del servidor frente a accesos no autorizados desde la red.

Conceptos clave

Section titled “Conceptos clave”
  • Regla de entrada (Inbound): Controla el tráfico que llega al servidor
  • Regla de salida (Outbound): Controla el tráfico que sale del servidor
  • Perfiles de red:
    • Dominio: Se aplica cuando el equipo está autenticado en un dominio AD
    • Privado: Para redes de confianza (oficina u hogar)
    • Público: Para redes públicas (máxima restricción)

Gestión desde la interfaz gráfica

Section titled “Gestión desde la interfaz gráfica”

Abre Windows Defender Firewall with Advanced Security ejecutando wf.msc:

  1. Ver reglas activas: Haz clic en Inbound Rules u Outbound Rules
  2. Crear una nueva regla: Clic derecho en la sección → New Rule…
    • Program: Para permitir/bloquear una aplicación concreta
    • Port: Para un puerto TCP o UDP específico
    • Predefined: Para servicios conocidos de Windows (RDP, DNS, SMB…)
    • Custom: Para reglas avanzadas con combinación de criterios
  3. Deshabilitar una regla: Clic derecho → Disable Rule
  4. Ver el estado por perfil: Panel izquierdo → Windows Defender Firewall with Advanced Security on Local Computer

No deshabilites el Firewall

Deshabilitar el Firewall de Windows expone toda la superficie del servidor. Si necesitas que un servicio sea accesible, crea una regla específica en lugar de apagar el firewall.

Auditoría y Visor de eventos

Section titled “Auditoría y Visor de eventos”

¿Qué es la auditoría?

Section titled “¿Qué es la auditoría?”

La auditoría de seguridad registra en el registro de eventos de Windows las acciones relevantes: inicios de sesión, cambios de permisos, creación de usuarios, acceso a archivos. Es fundamental para detectar incidentes y cumplir con normativas de seguridad.

Activar la auditoría de seguridad

Section titled “Activar la auditoría de seguridad”

Mediante directiva local (equipo independiente):

  1. Ejecuta secpol.msc
  2. Ve a Security Settings → Local Policies → Audit Policy
  3. Habilita los eventos que quieres auditar (éxito, fracaso o ambos):
    • Audit account logon events — Inicio de sesión en el dominio
    • Audit logon events — Inicio de sesión local en el equipo
    • Audit object access — Acceso a archivos y carpetas
    • Audit account management — Creación/modificación de cuentas
    • Audit policy change — Cambios en directivas de seguridad

Mediante GPO (dominio — recomendado):

  1. Abre gpmc.msc
  2. Edita la GPO aplicada al dominio o OU
  3. Ve a Computer Configuration → Windows Settings → Security Settings → Local Policies → Audit Policy

Actualizaciones del sistema (Windows Update)

Section titled “Actualizaciones del sistema (Windows Update)”

Mantener el servidor actualizado es una de las medidas de seguridad más efectivas. Muchos ataques explotan vulnerabilidades ya corregidas en actualizaciones que no se han aplicado.

WSUS (Windows Server Update Services) es el rol de Windows Server que centraliza la distribución de actualizaciones en la red, evitando que cada equipo descargue individualmente desde Internet.

Evaluación de la necesidad de protección

Section titled “Evaluación de la necesidad de protección”

Antes de configurar medidas de seguridad, hay que analizar qué proteger y de qué.

Principio del mínimo privilegio

Section titled “Principio del mínimo privilegio”

Cada usuario, servicio o proceso debe tener solo los permisos mínimos necesarios para su función.

Aplicación práctica:

  • No usar la cuenta Administrador para tareas cotidianas — crea cuentas con los permisos justos
  • Crear cuentas de servicio dedicadas con permisos específicos
  • Revisar periódicamente los usuarios con permisos elevados

Superficie de ataque

Section titled “Superficie de ataque”

Cuantos más servicios y puertos abiertos tenga un servidor, mayor es su superficie de ataque — la cantidad de puntos por donde podría ser comprometido.

Regla de oro

Si no necesitas un servicio, desactívalo. Cada servicio activo que no se usa es una potencial vía de entrada para un atacante y consume recursos innecesariamente.

Checklist de seguridad básica en Windows Server

Section titled “Checklist de seguridad básica en Windows Server”
  • Contraseña de administrador robusta y única (min. 12 caracteres, letras + números + símbolos)
  • Windows Defender Firewall activo en todos los perfiles
  • Solo los puertos estrictamente necesarios abiertos en el firewall
  • Windows Defender Antivirus activo y definiciones actualizadas
  • Actualizaciones del sistema al día (Windows Update o WSUS)
  • Auditoría de seguridad activada (al menos inicio de sesión y gestión de cuentas)
  • Cuentas de usuario con el mínimo privilegio necesario
  • RDP protegido con NLA y acceso restringido a IPs conocidas
  • SMB 1.0 deshabilitado
  • Copias de seguridad regulares y verificadas (regla 3-2-1)
  • Servicios no necesarios deshabilitados o detenidos
